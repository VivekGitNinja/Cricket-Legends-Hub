# Accessibility Report

## WCAG-oriented checklist

| Area | Status |
|------|--------|
| Skip to content link | Yes |
| Semantic structure | Yes |
| Keyboard navigation | Yes (nav, palette arrows/enter/esc) |
| Focus-visible styles | Yes |
| Icon button labels | Yes (`aria-label`) |
| Dialog semantics for palette | Yes (`role="dialog"`, `aria-modal`) |
| Reduced motion | Yes |
| Color contrast (dark UI) | Tuned for AA intent |
| Form labels | Yes on filters / selects |
| Alt text on avatars | Name-based |
| Progressbar for scroll | Yes |

## Known limitations

- External Wikipedia portrait images may fail; avatar falls back to initials
- Charts from Recharts are visual aids — tables accompany comparison metrics
